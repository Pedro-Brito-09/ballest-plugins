# Ballest plugins

Plugins for [Ballest of Them All](https://store.steampowered.com/app/3339810/), run by the
[Ballest plugin manager](https://github.com/AnythingGoes-ballest/ballest-plugin-manager). Install them from the
plugin manager's in-game browser.

| Plugin | What it does |
|---|---|
| [Practice Checkpoints](plugins/practice-checkpoints) | Save the ball anywhere on a track, with its speed, and go back to it to practise a section. |

Each plugin is in its own folder under `plugins/` and is versioned on its own: its release tags are
`<plugin id>-v<version>`, for example `practice-checkpoints-v0.3.0`.
